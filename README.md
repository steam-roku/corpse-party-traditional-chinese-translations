# Corpse Party (2021) Traditional Chinese Translation
## 屍體派對 (2021) 繁體中文翻譯

最近正埋首製作《Corpse Party》中文補丁。我沒有直接採用其他版本的翻譯，而是利用 AI 重新翻譯，並同時參考日文、英文和韓文版本，盡量確保內容和語氣都忠於原作。

## 目前已完成以下項目：
* 遊戲介面
* 全章節劇情（CH1～CH5、Extra）
* 第一章開場的血字畫面
* 物品名稱及描述
* 名牌一覽
* 結局一覽
* 地圖位置名稱

## 整個專案遵從以下原則：
1. 以日文原文為最高依據。
2. 英文、韓文作為參考。
3. 除了サッちゃん翻譯成「小幸」之外，其餘角色均保留日文名字，例如サチコ、篠崎あゆみ，也保留日式漢字寫法。
4. 地名及其他專有名詞則翻譯成繁體中文，但盡量保留原意，例如「天神小學校」不會簡化成「天神小學」。

## 日語敬稱處理方式如下：
* さん：學生之間翻譯成「同學」，例如「篠崎同學」；其他情況則依對象譯為先生、小姐、太太等。
* くん：學生之間同樣譯為「同學」，其他情況則保留為「君」。
* ちゃん：統一譯為「醬」（這個我自己看得比較習慣）。
* 先生：譯為「老師」。
